# HTTP API

The processing node listens on port 8000. Interactive docs are generated by FastAPI at
`/docs` (Swagger UI) and `/redoc`.

| Method | Path | Purpose |
| --- | --- | --- |
| `POST` | `/sensor-data` | Ingest one node reading; returns anomaly score and health index |
| `POST` | `/camera-frame` | Upload a raw JPEG; acknowledged immediately, analysed in the background |
| `GET` | `/camera-frame` | Latest raw JPEG |
| `GET` | `/camera-overlay` | Latest annotated frame (rust orange, break cyan) |
| `GET` | `/latest-verdict` | Current verdict, evidence and node state |
| `GET` | `/history` | Most recent readings (default 100) |
| `GET` | `/health` | Service, model, Ollama and buffer status |
| `GET` | `/` | Kiosk HMI |

## `POST /sensor-data`

```json
{
  "timestamp": "2026-09-23T00:35:24",
  "zone_id": "ZONE_A",
  "gps": { "lat": 9.9252, "lon": 78.1198, "valid": true },
  "accel": { "x": 0.12, "y": 0.03, "z": 9.81 },
  "gyro": { "x": 0.01, "y": 0.02, "z": 0.0 },
  "angle": { "x": 0.0, "y": 0.0, "z": 0.0 },
  "acoustic_rms": 0.28,
  "acoustic_peak_freq": 185.0,
  "accel_rms_30s": 0.04,
  "crack_score": 0.0,
  "crack_detected": false,
  "crack_count": 0,
  "still": true,
  "imu_calibrated": true,
  "mic_ok": true
}
```

Units: acceleration in m/s², gyro in °/s, frequency in Hz. Non-finite numbers (`NaN`,
`Infinity`) are rejected with `422`.

Response:

```json
{ "status": "ok", "anomaly_score": 0.61, "anomaly_label": 1, "health_index": 98.7, "mode": "STILL" }
```

`anomaly_label` follows the Isolation Forest convention: `1` healthy, `-1` anomalous.
`mode` is `CAL` while the IMU calibrates, `STILL` on a resting node, `MOVE` while handled.

## `POST /camera-frame`

Body: raw JPEG bytes (`Content-Type: image/jpeg`). The response carries the last confirmed vision
state so the node never waits on OpenCV or the language model:

```json
{
  "accepted": true,
  "queued": true,
  "status": "OK",
  "rust_detected": false,
  "rust_score": 0.0,
  "break_detected": false,
  "crack_score": 0.0,
  "crack_count": 0,
  "vision_engine": "opencv"
}
```

`queued` is `false` when the vision worker was still busy; the frame still updates the preview.

## `GET /latest-verdict`

Key fields:

| Field | Description |
| --- | --- |
| `status` | `NORMAL`, `WARNING` or `CRITICAL` — always from the physics/vision stages |
| `fault_type`, `recommended_action`, `reasoning` | operator text (Gemma 4 when fresh and in agreement, otherwise the rule engine) |
| `confidence` | 0–1 |
| `health_index` | 0–100 |
| `time_to_fault` | estimate while not NORMAL, e.g. `"2.0 hours"` |
| `reasons`, `contributions` | per-signal evidence behind the verdict |
| `sustained`, `forest_agrees` | debounce state and Isolation Forest corroboration |
| `node_online`, `node_age_s` | node considered online if a reading arrived in the last 15 s |
| `camera_status`, `camera_note` | `OK`, `DARK`, `BLOWN_OUT`, `BLURRED`, `NO_TARGET`, `NO_FRAME` |
| `rust_detected`, `break_detected` | confirmed camera findings |
| `ai_source`, `ai_analysed_at` | where the text came from and when |
